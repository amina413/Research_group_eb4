# 04 — Data Contract (single source of truth for names)

This file is the **agreement between frontend and backend**. Every table, column,
enum value, function, bucket and route name used anywhere in the code must match
this file exactly. If a name is not here, it does not exist yet.

- **Status `Agreed`** = confirmed by the team. Safe to build against.
- **Status `Proposed`** = drafted by frontend, waiting for backend sign-off.
  Frontend may build against it using mocks; backend may rename it **only** by
  updating this file + `contract/` in a contract PR (see `05-workflow.md`).

Naming conventions (Agreed):

| Thing | Convention | Example |
|---|---|---|
| Tables | `snake_case`, plural | `task_responses` |
| Columns | `snake_case`, singular | `target_participants` |
| Primary keys | `id` (`uuid`, default `gen_random_uuid()`) | `id` |
| Foreign keys | `<singular_table>_id` | `study_id` |
| Timestamps | `timestamptz`, suffix `_at` | `approved_at` |
| Dates (no time) | `date`, suffix `_date` | `start_date` |
| Booleans | prefix `is_` / `has_` | `is_active` |
| Enums (Postgres types) | `snake_case` type, lowercase values | `study_status` → `recruiting` |
| RPC (Postgres functions) | `snake_case` verb first | `approve_enrolment` |
| Edge Functions | `kebab-case` | `delete-account` |
| Frontend TS types | generated by Supabase CLI, never hand-renamed | `Tables<'studies'>` |

Spelling: British — `enrolment`, `enrolments` (one L). Do **not** mix with `enrollment`.

## 3. JSON shapes

**Shape A — `task_questions.options`**

```json
// single_choice / multi_choice
{ "choices": [ { "value": "a", "label": "Never" }, { "value": "b", "label": "Sometimes" } ] }
// scale
{ "min": 1, "max": 5, "min_label": "Not at all", "max_label": "Extremely" }
// number
{ "min": 0, "max": 120, "unit": "minutes" }
// short_text / long_text / yes_no
null
```

**Shape B — `task_responses.answers`** (keyed by `task_questions.id`)

```json
{
  "3f1c...-question-uuid": "b",            // single_choice → value
  "8a2d...-question-uuid": ["a", "c"],     // multi_choice → values
  "c9e0...-question-uuid": 4,              // scale / number
  "d117...-question-uuid": true,           // yes_no
  "e55b...-question-uuid": "Free text"     // short_text / long_text
}
```

## 4. Database functions (RPC) — called with `supabase.rpc(name, args)`

| Function | Args | Returns | Who can call | Purpose | Status |
|---|---|---|---|---|---|
| `get_study_by_source_code` | `p_code text` | `{ study_id, title, description, eligibility_criteria, status, spots_left }` | anyone (anon) | Landing page for `/join/:code`. Never exposes researcher data | Proposed |
| `apply_to_study` | `p_study_id uuid, p_source_code text, p_answers jsonb` | `enrolments` row | participant | Creates `pending` enrolment + onboarding response in one go. Fails if study not `recruiting` | Proposed |
| `approve_enrolment` | `p_enrolment_id uuid` | `enrolments` row | researcher (own study), admin | Sets `approved`, bumps `approved_count`, sets study `full` at target, creates notification | Proposed |
| `reject_enrolment` | `p_enrolment_id uuid, p_reason text` | `enrolments` row | researcher (own study), admin | Sets `rejected`, creates notification | Proposed |
| `get_participation_summary` | `p_enrolment_id uuid` | see below | participant (own), researcher (own study), admin | Streak / level / points for dashboard | Proposed |
| `get_study_stats` | `p_study_id uuid` | `{ applied, pending, approved, rejected, by_source: [{ label, code, count }] }` | researcher (own study), admin | Researcher dashboard + source tracking chart | Proposed |
| `evaluate_streaks` | none | `void` | pg_cron only | Nightly job: updates streak state, sends grace/broken notifications, unlocks rewards | Proposed |

`get_participation_summary` returns:

```json
{
  "enrolment_id": "uuid",
  "window_days": 14,
  "expected_count": 14,
  "completed_count": 12,
  "participation_rate": 0.857,
  "streak_status": "active",
  "grace_days_left": null,
  "total_points": 340,
  "current_level": 4,
  "points_to_next_level": 60,
  "next_reward": { "reward_id": "uuid", "title": "£10 voucher", "level_required": 5 }
}
```
