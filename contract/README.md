# /contract

Shared code that both sides agree on. **Owned jointly** — changes need approval
from both frontend and backend (see `docs/05-workflow.md`).

| File | What | Who writes it |
|---|---|---|
| `database.types.ts` | Table rows, enums, RPC return shapes, name constants | Hand-written now; later generated by backend via `supabase gen types` |
| `routes.ts` | Frontend URL paths (used in QR codes and emails) | Frontend |

The human-readable version of all of this is `docs/04-data-contract.md`.
The two must always match.

When the backend generates types, keep the extra exports at the bottom of the
current file (`TABLES`, `RPC`, `EDGE_FUNCTIONS`, `BUCKETS`, RPC return interfaces)
by moving them into `contract/constants.ts` and re-exporting — so frontend imports
keep working.
